# Production Check — Alistron Website

Tracking of issues found while reviewing the production deployment.
Legend: **[P1]** critical / user-facing · **[P2]** important · **[P3]** polish
Status: `DONE` fixed · `TODO` open · `BLOCKED` waiting on assets/specs

## Performance

- [x] **DONE — Heavy images / slow loading.** Project, journey and team photos were
  served raw (300 KB–1 MB each, ~6.4 MB on the pages that use them). Re-encoded
  to WebP (`npm run optimize:images`), ~83% smaller (used set ~6.4 MB -> ~1.0 MB).
  Project cards alone drop from ~4 MB to ~0.7 MB.
- [x] **DONE — No cache headers.** Production returned
  `cache-control: public, max-age=0, must-revalidate` for everything. Added
  cache rules (immutable for `/_next/static/*`, 30-day cache for images and icons,
  revalidate for HTML): `.htaccess` on HelioHost, `_headers` on Cloudflare Pages.
- [x] **DONE [P3]** Unused photos (~5 MB) removed from `public/images`, and later
  deleted from the repo (`assets/unused-photos/`, recoverable from git history).
- [x] **DONE** Removed the unused `resend` npm package (both contact endpoints call
  the Resend REST API directly).
- [x] **DONE** Removed the leftover Next.js starter SVGs (`next.svg`,
  `vercel.svg`, `file.svg`, `globe.svg`, `window.svg`) from `public/`.

## Brand / assets

- [x] **DONE — Logos.** Brand applied from the logo system board
  (`assets/brand/alistron-logo-board.png`). Vector submark + Michroma wordmark in
  `src/components/Logo.tsx` (navbar, footer); hero emblem, favicon, `icon.svg`,
  `apple-icon.png` and `opengraph-image.jpg` generated by
  `node scripts/generate-brand-assets.mjs`.
- [x] **DONE [P3]** Social share image and `apple-touch-icon` now come from the
  `src/app` file conventions; `theme-color` set in `layout.tsx`.

  Cloudflare worker, Resend via cURL). Tested against Apache 2.4 locally.
